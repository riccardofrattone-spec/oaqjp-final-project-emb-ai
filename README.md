# Final project

IBM Developing AI Applications with Python and Flask: emotion detection using
the Watson NLP service, a Python package, unit tests, and a Flask interface.

This version was prepared with Codex assistance during the current session.
It is a new draft, not a recovered copy of previously completed work.

The starter `templates/` and `static/` directories come from the IBM repository.

```sh
python3 -m pip install requests flask pylint
python3 -m unittest -v test_emotion_detection
pylint server.py
python3 server.py
```
